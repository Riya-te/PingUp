# 🚀 PingUp — Modern Social Media Platform

PingUp is a full-stack social media web application built using the MERN stack with modern scalable architecture.  
Users can create posts, upload stories, send messages, connect with others, and interact in real time...

---

# 🌟 Features

## 🔐 Authentication
- Clerk Authentication
- Secure Login / Signup
- Protected Routes

## 👤 User System
- User Profiles
- Follow / Unfollow
- Connection Requests
- Profile Update
- Cover & Profile Images

## 📝 Posts
- Create Posts
- Upload Images
- Like / Unlike Posts
- Comment System
- Feed System

## 📸 Stories
- Instagram-style Stories
- Auto Delete after 24 Hours
- Story View Tracking

## 💬 Messaging
- Real-time-ready Chat System
- Text Messages
- Image Messages
- Read Receipts

## 📧 Notifications
- Email Notifications using Nodemailer
- Connection Request Alerts

## ⚡ Backend Architecture
- REST APIs
- Modular MVC Structure
- MongoDB Database
- ImageKit Media Uploads
- Inngest Background Events
- Socket.IO Integration

---
